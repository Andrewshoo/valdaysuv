# SEO и поисковые роботы

## Настройки в проекте

- Основной адрес: https://valdaysuv.ru/ (HTTPS, без www).
- У каждой страницы собственные title, description и canonical.
- Индексация главной и политики разрешена. Политика имеет собственный canonical.
- robots.txt разрешает обход, включая src и img; указан sitemap.xml.
- Правила для всех роботов подходят Googlebot, YandexBot и Bingbot.
- Каталог находится в исходном HTML, доступен без JavaScript. Корзина включается
  скриптом, а без JavaScript доступны телефон и email для заказа.
- Данные товара редактируются через админку или content/products/*.json.
  Сборщик автоматически формирует data-product-* и видимый текст.
- JSON-LD LocalBusiness и WebSite формируется из content/settings/site.json:
  адрес, телефон, email и часы работы обновляются вместе с сайтом.
- Open Graph и Twitter Card задают превью ссылок. Не являются гарантией позиций.
- Product/Offer, цены, рейтинги и отзывы не добавлены: подтверждённых цен и
  отзывов в проекте нет. Не задавайте нулевую цену вместо «по запросу».
- В sitemap только существующие канонические страницы. Якоря каталога не являются
  отдельными страницами. lastmod можно добавить при наличии достоверной даты
  изменения содержания; не обновлять автоматически при каждом посещении.

## После публикации

1. В GitHub Pages проверить домен valdaysuv.ru и включить Enforce HTTPS.
   Проверить, что HTTP и www ведут постоянным редиректом на основной HTTPS-адрес.
   HTML canonical не заменяет HTTP-редиректы; их настраивает хостинг/DNS.
2. Проверить ответы 200 для /, /privacy.html, /robots.txt, /sitemap.xml и ресурсов.
   Несуществующий адрес должен возвращать HTTP 404, а не главную с кодом 200.
3. Добавить домен в Яндекс Вебмастер и Google Search Console. Подтвердить владение
   через DNS TXT или выданный сервисом HTML-файл/метатег. Реальные токены нужно
   получить в аккаунтах владельца; заглушек в проекте нет.
4. Отправить https://valdaysuv.ru/sitemap.xml в оба сервиса, проверить robots.txt
   и запросить переобход главной. В Search Console использовать проверку URL,
   в Вебмастере — проверку страницы и переобход. Следить за ошибками индексации.
5. При необходимости подключить Bing Webmaster Tools и отправить ту же карту.
6. Создать или актуализировать карточку мастерской в Яндекс Бизнесе и Google
   Business Profile, если сервис доступен для организации. Адрес, телефон,
   название и часы работы должны совпадать с сайтом.
7. Проверить JSON-LD в Google Rich Results Test и Schema Markup Validator,
   мобильную версию и скорость — в PageSpeed Insights.
8. При необходимости подключить Яндекс Метрику / GA4 с настоящими ID счётчиков
   и настроить цели: контакт, добавление в корзину, переход к отправке заказа.
   Счётчики не обязательны для индексации. Сформированный заказ не означает
   отправку или покупку. При подключении обновить политику конфиденциальности.

## Дальнейшее развитие

- Сопоставить фотографии и добавить реальные размеры, материалы и цены товаров.
- При расширении ассортимента создать отдельные содержательные страницы товаров
  с уникальными URL и затем добавить их в sitemap и Product-разметку.
- Добавлять только подтверждённые сведения о производстве, доставке и оплате.
- Проверять показатели загрузки, оптимизировать фото и сохранять их размеры.

robots.txt управляет обходом, но не защищает файлы и сам по себе не гарантирует
удаление URL из поиска. Секреты не публикуются. Для запрета индексации страницы
используется noindex с разрешённым обходом, а для приватности — контроль доступа.
Настройки не гарантируют сроки индексации, расширенные сниппеты или позиции.
